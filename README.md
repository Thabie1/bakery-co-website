Bakery Co. Website Project

Project Overview
Bakery Co. is an established local artisanal bakery specializing in handcrafted sourdough breads, fresh pastries, custom celebratory cakes, and hot/cold beverages. This project delivers a responsive, 5-page website to establish an online brand presence and streamline customer ordering.

───

File Structure
• index.html — Home page featuring high-impact hero banner, featured products, and call-to-action sections.
• about.html — About Us page covering company mission, core values, and baking process.
• products.html — Menu / Product catalogue categorizing breads, pastries, and beverages.
• enquiry.html — Custom cake inquiry form allowing customers to place custom orders.
• contact.html — Contact page displaying trading hours, contact details, and an embedded map.
• css/ — Sub-folder reserved for external stylesheet files (style.css).
• js/ — Sub-folder reserved for external JavaScript files (script.js).
• images/ — Sub-folder reserved for website image assets.

───

Technologies Used
• HTML5: Semantic markup structure (<header>, <nav>, <main>, <section>, <footer>).
• CSS3: Responsive layout styling, media queries, and color themes (Planned for PoE Part 2).
• JavaScript: Form validation and interactive UI components (Planned for PoE Part 2).
• Git & GitHub: Version control and public repository hosting.
